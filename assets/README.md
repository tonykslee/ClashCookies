# Official Duskits currency symbol

![Official Duskit coin: gold crescent moon and star on purple with gold rim](./duskit-128.png)

- **Canonical repository icon:** [`duskit-128.png`](./duskit-128.png), 128 × 128 PNG with transparent background, derived from the owner-selected uploaded artwork. The repository rendition is palette-optimized for small emoji use; retain the supplied original when producing larger variants.
- **Status:** Adopted by the project owner on 2026-11-13 as the official currency symbol for **Duskits** (singular **Duskit**).
- **Visual identity:** circular gold-rimmed purple coin featuring a gold crescent moon and a gold four-point star.
- **Intended use:** illustrate Duskits balances, earned rewards, costs, history, Dusk Market offerings and other clearly currency-related communications. In plain text, write **Duskits** for accessibility; the image is not a substitute for identifying the currency.
- **Discord:** The PNG may be uploaded as a custom guild/application emoji (suggested short name `duskit`), but its Discord emoji **ID and mention syntax are not yet verified**. Do not hardcode an invented `<:duskit:ID>` token or claim it is already installed. Runtime use of a custom emoji requires a separately tested implementation.
- **Boundaries:** The icon is branding only. It does **not** authorize Duskits issuance, historical credit, spending, role fulfillment, production deployment or giveaways.

See [`docs/roadmaps/dusk-economy.md`](../docs/roadmaps/dusk-economy.md) for the living economy decisions and implementation status.
